# Базовые конструкции языка Go

Решения 10 практических заданий на условные операторы, циклы и функции.
Каждое задание вынесено в отдельную папку, общий код ввода находится в пакете `internal/console`.

## Структура

| № | Папка | Задание |
|---|-------|---------|
| 1 | `task01_calculator` | Калькулятор с проверкой деления на ноль |
| 2 | `task02_number_analysis` | Анализ числа: знак, чётность, делимость на 3 и 5 |
| 3 | `task03_sum_average` | Сумма и среднее от 1 до N |
| 4 | `task04_multiplication_table` | Таблица умножения через функцию |
| 5 | `task05_max_min` | Максимум и минимум из N чисел |
| 6 | `task06_count_signs` | Количество положительных, отрицательных чисел и нулей |
| 7 | `task07_filtered_sum` | Сумма только подходящих чисел |
| 8 | `task08_prime` | Проверка простого числа |
| 9 | `task09_atm` | Мини-банкомат |
| 10 | `task10_statistics` | Статистика последовательности |
| — | `internal/console` | Чтение и проверка ввода, форматирование чисел |

## Требования

Go 1.21 или новее.

## Запуск и тесты

```bash
go run ./task01_calculator     # запуск отдельного задания
go test ./...                  # запуск всех тестов
go vet ./...                   # статический анализ
```

## Описание заданий

**1. Калькулятор.** Операции с двумя числами: `+`, `-`, `*`, `/`, `%` (остаток от деления), `^` (возведение в степень).
Операции с одним числом: `sqrt` (квадратный корень), `sq` (квадрат). Проверяются деление и остаток от деления на ноль,
корень из отрицательного числа, неопределённый результат (например, `(-8) ^ (1/3)`) и переполнение.
После вычисления можно выполнить следующее без перезапуска программы.

**2. Анализ числа.** Для целого числа выводятся знак (положительное, отрицательное, ноль), чётность
и делимость на 3 и на 5.

**3. Сумма и среднее.** Сумма чисел от 1 до N вычисляется в цикле и сверяется с формулой n(n+1)/2.
N ограничено значением 1 000 000.

**4. Таблица умножения.** Функция `printTable(w, n, limit)` выводит таблицу умножения числа n
на множители от 1 до limit с выравниванием столбцов.

**5. Максимум и минимум.** Выводятся максимальное и минимальное значения и их порядковые номера.

**6. Подсчёт знаков.** Подсчитываются положительные числа, отрицательные числа и нули.

**7. Сумма подходящих чисел.** Вычисляется сумма чисел от 1 до N, которые одновременно чётные и делятся на 3
(функция `isSuitable`, условие `n%2 == 0 && n%3 == 0`). Выводятся количество подходящих чисел и их сумма.

**8. Простое число.** Функция `isPrime` проверяет делители до квадратного корня из числа.
Для составного числа выводится его наименьший делитель.

**9. Мини-банкомат.** Пользователь вводит начальный баланс, затем выбирает действия в меню: просмотр баланса, пополнение, снятие с проверкой достаточности средств и история операций.
Суммы хранятся в копейках (`int64`), чтобы избежать ошибок округления вещественных чисел.
Принимаются суммы с точностью до копеек, не более 1 000 000 руб. за операцию.

**10. Статистика.** Для N целых чисел выводятся сумма, среднее значение, максимум, минимум,
количество чётных и нечётных чисел. Дополнительно рассчитываются размах, медиана, дисперсия и стандартное отклонение.

## Проверка ввода

Все программы повторяют запрос при некорректном вводе: нечисловых значениях, значениях вне допустимого
диапазона, `inf` и `NaN`. Дробные числа можно вводить как через точку, так и через запятую.
При завершении ввода (Ctrl+D) программа корректно завершается.
